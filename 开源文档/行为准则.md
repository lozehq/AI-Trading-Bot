# 行为准则

为营造开放、友善、包容、专业的社区氛围，所有参与者（维护者、贡献者、用户）应遵守本准则。

## 我们的承诺
- 以尊重和同理心对待所有人
- 接纳不同观点与经验
- 积极、建设性地沟通与协作
- 关注问题本身，不攻击个人

## 不当行为示例（包括但不限于）
- 带有歧视、骚扰、恐吓、侮辱的言论或图像
- 公开他人隐私信息（人肉搜索）
- 蓄意破坏、刷屏、钓鱼式挑衅
- 性暗示或任何形式的不受欢迎的关注

## 适用范围
- 本仓库与其衍生项目
- Issue / PR / 讨论区 / 评论
- 与项目相关的社交平台与线下活动

## 违规处理
- 维护者可对不当内容进行编辑、删除、锁定
- 对屡次或恶劣违规者，可限制或移除其参与资格
- 严重情况可上报相关平台或机构处理

## 举报方式
- 在仓库创建 Issue 简要描述情况，并请求维护者私信以继续沟通
- 如涉及隐私或人身安全，请仅提供必要线索，不要在公开渠道披露细节

## 参考
本准则参考了开源社区通行做法（如 Contributor Covenant）。我们将根据社区反馈持续改进。
