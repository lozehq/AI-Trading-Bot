# 使用说明（快速上手）

本指南告诉你需要设置哪些内容，如何在本地或服务器快速跑起来。建议先在「paper/demo」模式充分验证，再切换到「live」。

---

## 1) 环境准备
- Node.js 18 或 20
- 复制环境模板并编辑

```bash
cp env.example .env
# Windows 可直接复制文件并改名为 .env
```

---

## 2) 必配/强烈建议的变量
- AI 服务（建议设置，否则 AI 分析受限）
```env
DEEPSEEK_API_KEY=你的AI密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1   # 或 iflow: https://apis.iflow.cn/v1
DEEPSEEK_MODEL=deepseek-chat
```

- 服务器端口/CORS（按需调整）
```env
PORT=3000
WS_PORT=3001
ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
```

- 数据源与默认交易所（默认即可）
```env
DATA_SOURCE=ccxt
DEFAULT_EXCHANGE=okx
DEFAULT_MARKET_TYPE=spot
```

---

## 3) 真实交易（可选，默认不开启）
强烈建议先用「demo」或「paper」模式验证 1–2 周，再考虑「live」。

- OKX API 凭证（模拟/真实都需要）
```env
OKX_API_KEY=你的OKX_API_KEY
OKX_API_SECRET=你的OKX_API_SECRET
OKX_API_PASSPHRASE=你的口令
```

- 交易模式与模拟盘开关（推荐先 demo）
```env
TRADING_MODE=demo   # paper|demo|live
OKX_SIMULATED=true  # 模拟盘 true，实盘 false
```

- 风险控制（按需调整）
```env
MAX_TRADE_AMOUNT=1000
MAX_POSITIONS=5
MAX_DAILY_TRADES=20
```

安全建议：
- 在 OKX 启用「IP 白名单」；绝对不要开启「提现权限」
- 真实交易从小额开始，给风险留缓冲

---

## 4) 代理（国内/被墙场景可选）
若访问交易所或 AI API 需要代理，可设置：
```env
PROXY_URL=http://127.0.0.1:7890
```
更多配置见：docs/PROXY_SETUP_GUIDE.md

---

## 5) 高级/可选参数
- 反趋势保护/AI 校准（按需）
```env
AI_VALIDATION_TARGET_WINRATE=0.60
ANTI_TREND_HARD_GATE_PCT=85
```

- 内部接口密钥（仅用于受保护内部端点）
```env
INTERNAL_API_KEY=强随机密钥
```

---

## 6) 启动与验证
- Windows 一键启动
```bash
START-ALL.bat
```

- Linux/Mac（开发模式）
```bash
npm install && cd client && npm install && cd ..
npm run dev
```

- 健康检查
```bash
curl http://localhost:3000/health
```

- OKX 测试（已配置 OKX 后）
```bash
curl "http://localhost:3000/api/okx/trade/balance?mode=demo"
```

---

## 7) 安全与合规
- 切勿将 .env、日志、数据库提交到 Git（仓库已忽略）
- 日志与控制台输出已自动脱敏，但生产建议最小化日志
- 真实交易风险高：paper/demo → live；严格额度与频次限制
- 许可与免责：见《开源许可-商业可用与免责.md》，商业可用但作者免责

---

## 8) 常见问题
- AI 不工作？检查 DEEPSEEK_API_KEY、DEEPSEEK_BASE_URL 是否正确。
- OKX 报认证错误？检查三件套（Key/Secret/Passphrase）和是否为 demo 模式。
- 前端连不上后端？确认 PORT/WS_PORT、防火墙与前端代理配置。
- 需要更多文档：docs/OKX_TRADING_SETUP.md、docs/OKX_API_REFERENCE.md、docs/PROXY_SETUP_GUIDE.md
