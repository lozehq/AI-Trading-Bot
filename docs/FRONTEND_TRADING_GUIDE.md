## 💰 手动交易面板功能详解

### 1. 账户余额区域

显示内容：
- **总资产** - 账户总价值（USDT计价）
- **可用余额** - 可用于交易的资金
- **冻结资金** - 未成交订单占用的资金
- **账户类型** - SPOT（现货）/ SWAP（合约）

**多币种余额**：
- 显示所有持有的加密货币
- 实时更新余额

### 2. 创建订单区域

#### 交易对选择
```
支持的交易对：
• BTC/USDT - 比特币
• ETH/USDT - 以太坊
• BNB/USDT - 币安币
• SOL/USDT - Solana
• XRP/USDT - 瑞波币
• ADA/USDT - 艾达币
```

选择交易对后会自动显示当前价格。

#### 订单方向
- 🟢 **买入** (BUY) - 购买加密货币
- 🔴 **卖出** (SELL) - 出售加密货币

#### 订单类型

##### 限价单 (LIMIT)
- **说明**：指定价格下单
- **优点**：可以设定理想价格
- **缺点**：不一定能成交
- **适用**：有明确目标价位时

**示例**：
```
当前 BTC 价格: $50,000
设置限价单买入: $49,500
→ 当价格跌到 $49,500 时自动成交
```

##### 市价单 (MARKET)
- **说明**：按当前市场价立即成交
- **优点**：立即成交
- **缺点**：价格可能波动
- **适用**：需要快速进场时

#### 交易数量

**输入方式**：
1. 直接输入数量
2. 使用快捷按钮：25% / 50% / 75% / 100%

**自动计算**：
- 系统会显示总计金额
- 检查可用余额是否足够

**示例**：
```
BTC 价格: $50,000
点击 50% 按钮
可用余额: 10,000 USDT
→ 自动计算数量: 0.1 BTC
→ 总计: 5,000 USDT
```

#### 止损止盈（可选）

##### 止损价 (Stop Loss)
- **作用**：限制最大亏损
- **触发**：价格跌破止损价时自动卖出
- **建议**：设置在入场价下方 3-5%

**示例**：
```
买入 BTC 价格: $50,000
止损价设置: $48,500 (下跌3%)
→ 如果跌到 $48,500，自动卖出
→ 最大亏损: $1,500
```

##### 止盈价 (Take Profit)
- **作用**：锁定利润
- **触发**：价格达到止盈价时自动卖出
- **建议**：设置在入场价上方 8-10%

**示例**：
```
买入 BTC 价格: $50,000
止盈价设置: $55,000 (上涨10%)
→ 如果涨到 $55,000，自动卖出
→ 锁定利润: $5,000
```

### 3. 未成交订单区域

## ⚠️ 重要提示

### 使用真实交易前

**必须完成**：
- [ ] ✅ 已在模拟盘测试至少 1 周
- [ ] ✅ 熟悉所有操作流程
- [ ] ✅ 理解止损止盈机制
- [ ] ✅ 配置了 OKX API 凭证
- [ ] ✅ 测试了 API 连接（`node scripts/test-okx-api.js live`）
- [ ] ✅ 设置了合理的风险参数

**风险控制**：
```
建议设置：
• 单笔最大金额: 总资金的 2-5%
• 止损百分比: 3-5%
• 止盈百分比: 8-15%
• 初始投入: 100-500 USDT
```

### 常见错误

#### 1. API Key 无效
```
错误: Invalid OK-ACCESS-KEY (50111)
解决: 
1. 检查 .env 文件中的 OKX_API_KEY
2. 确保已在 OKX 创建 API
3. 运行测试: node scripts/test-okx-api.js
```

#### 2. 余额不足
```
错误: 下单数量过小，最小数量: X
解决:
1. 增加交易数量
2. 检查可用余额
3. 查看交易对最小限制
```

#### 3. 订单被拒绝
```
错误: 订单提交失败
解决:
1. 检查网络连接
2. 确认交易模式是否正确
3. 查看服务器日志: pm2 logs ai-server
```
