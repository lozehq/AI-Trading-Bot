## 🚀 配置步骤

### 步骤 1: 获取 OKX API 凭证

1. 登录 [OKX 官网](https://www.okx.com)
2. 进入 **账户** → **API** 管理
3. 创建 **V5 API 密钥**
4. 复制以下三个值：
   - ✅ API Key
   - ✅ Secret Key
   - ✅ Passphrase

**⚠️ 重要**：Secret Key 只显示一次，请立即保存！

---

### 步骤 2: 在 UI 中填写凭证

#### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| **API Key** | 您的 OKX API 密钥 | `a6516148-bc5b-...` |
| **Secret Key** | 您的 OKX API 密钥 | `BB783CCAA5ED1...` |
| **Passphrase** | 您创建 API 时设置的密码 | `Hwb123123..` |

#### 配置选项

**使用模拟盘（Testnet）**
- ✅ **推荐勾选**：使用虚拟资金测试
- ❌ 不勾选：使用真实资金（危险）

**启用真实交易（危险）**
- ⚠️ **仅在模拟盘关闭时可用**
- ⚠️ **谨慎使用**：会使用真实资金

---

### 步骤 3: 保存配置

1. 填写完所有字段
2. 点击 **"💾 保存配置"** 按钮
3. 等待提示：`✅ OKX配置保存成功`

---

### 步骤 4: 测试连接（可选）

1. 点击 **"🛡️ 测试连接"** 按钮
2. 系统会测试 API 连接
3. 成功：`✅ OKX连接测试成功`
4. 失败：显示错误信息

---

### 步骤 5: 重启服务器

**⚠️ 重要**：配置保存后，必须重启服务器才能生效！

```bash
# 停止服务器（在终端按 Ctrl+C）
# 然后重新启动
npm run dev
```

## 🔒 安全特性

### 1. 密钥加密存储

所有敏感信息都使用 **AES-256-CBC** 加密存储在数据库中。

```
原始密钥: a6516148-bc5b-43c2-ae08-0fec463be1cb
         ↓ 加密
加密后:   U2FsdGVkX1+... (存储在数据库)
```

### 2. 密钥不回填

已保存的密钥**永远不会**显示在输入框中。

```
首次配置:  [输入OKX API Key          ]
已保存:    [已保存，留空不修改        ]
```

### 3. 显示/隐藏切换

点击 👁️ 图标可切换密钥显示状态。

```
隐藏: [••••••••••••••••••••]  [👁️]
显示: [a6516148-bc5b-43c2-...] [👁️]
```

## 💡 常见问题

### Q1: 配置保存后，系统仍提示 API 未配置？

**A**: 需要重启服务器！

```bash
# 停止服务器（Ctrl+C）
npm run dev
```

---

### Q2: 测试连接失败，提示 "Invalid OK-ACCESS-KEY"？

**A**: 可能的原因：

1. ❌ API Key 复制错误（有多余空格）
2. ❌ Secret Key 错误
3. ❌ Passphrase 错误
4. ❌ IP 未加入白名单

**解决方案**：
1. 重新复制 API 凭证（确保无空格）
2. 检查 OKX 网站的 IP 白名单设置

---

### Q3: 如何修改已保存的配置？

**A**: 直接在输入框中输入新值即可。

- **留空** = 保持原值不变
- **输入新值** = 更新为新值

---

### Q4: 如何切换到真实交易？

**A**: 按以下步骤操作：

1. ⚠️ **确保您已充分测试**
2. 取消勾选 "使用模拟盘（Testnet）"
3. 勾选 "启用真实交易（危险）"
4. 保存配置
5. 重启服务器

⚠️ **警告**：真实交易会使用真实资金，请谨慎！
