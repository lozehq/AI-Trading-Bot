系统已经完整实现了 OKX API 的前端配置功能，您可以通过 UI 界面轻松配置 OKX API 凭证，无需手动编辑 `.env` 文件。

   - ✅ OKX Passphrase 输入

## 🚀 使用步骤

### 第 1 步：打开设置面板

1. 启动前端应用（`http://localhost:5173`）
2. 点击右上角的 **设置图标** ⚙️
3. 或者使用快捷键（如果有配置）

### 第 2 步：切换到 OKX 配置标签

1. 在设置面板中，点击 **"OKX配置"** 标签
2. 您会看到 OKX API 配置表单

### 第 3 步：填写 OKX API 凭证

#### 输入字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| **API Key** | OKX API 密钥 | `a6516148-bc5b-43c2-ae08-0fec463be1cb` |
| **Secret Key** | OKX API 密钥 | `BB783CCAA5ED1FF629CA2D2ECAB84678` |
| **Passphrase** | OKX API 密码短语 | `Hwb123123..` |

#### 配置选项

- **使用模拟盘（Testnet）**
  - ✅ 勾选：使用 OKX 模拟盘（虚拟资金）
  - ❌ 不勾选：使用真实交易环境

- **启用真实交易（危险）**
  - ⚠️ 仅在模拟盘关闭时可用
  - ⚠️ 启用后会使用真实资金交易
  - ⚠️ 请谨慎使用！

### 第 4 步：保存配置

1. 填写完所有字段后，点击 **"保存配置"** 按钮
2. 系统会将配置加密保存到数据库
3. 成功后会显示绿色提示：`OKX配置保存成功`

### 第 5 步：测试连接（可选）

1. 点击 **"测试连接"** 按钮
2. 系统会尝试连接 OKX API 并获取账户余额
3. 成功：显示 `OKX连接测试成功`
4. 失败：显示错误信息（如 API 密钥无效、IP 未白名单等）

## 🔒 安全特性详解

### 1. 密钥加密存储

所有敏感信息（API Key、Secret Key、Passphrase）都使用 **AES-256-CBC** 加密后存储在数据库中。

```javascript
// 加密示例（自动处理）
const encrypted = encrypt(apiKey); // AES-256-CBC
```

### 2. 密钥不回填

为了安全，已保存的密钥**永远不会**回填到输入框中。

- **首次配置**：输入框显示占位符 `"输入OKX API Key"`
- **已保存**：输入框显示 `"已保存，留空不修改"`
- **修改**：只需输入新值，留空则保持原值不变

### 3. 密钥显示/隐藏

每个密钥输入框都有 👁️ 图标，点击可切换显示/隐藏。

- **隐藏模式**（默认）：显示为 `••••••••`
- **显示模式**：显示明文

### 4. 安全警告

配置页面顶部有黄色警告框，提醒您：

- ✅ 使用只读或受限权限的 API 密钥
- ✅ 不要授予 API "提现" 权限
- ✅ 建议先在模拟盘测试
- ✅ 启用 IP 白名单限制

## 🔧 故障排除

### 问题 1: 保存失败

**错误信息**: `保存失败: ...`

**可能原因**:
1. 数据库连接失败
2. 加密服务异常
3. 网络问题

**解决方案**:
1. 检查服务器日志
2. 确认数据库文件存在（`data/trading.db`）
3. 重启服务器

---

### 问题 2: 测试连接失败

**错误信息**: `Invalid OK-ACCESS-KEY`

**可能原因**:
1. API Key 错误
2. Secret Key 错误
3. Passphrase 错误
4. IP 未加入白名单

**解决方案**:
1. 重新检查 OKX 网站上的 API 凭证
2. 确认复制时没有多余空格
3. 检查 IP 白名单设置

---

### 问题 3: 配置未生效

**症状**: 保存成功但系统仍提示 API 未配置

**可能原因**:
1. 配置保存到数据库，但未同步到环境变量
2. 服务器未重启

**解决方案**:
1. **重启服务器**（重要！）
   ```bash
   # 停止服务器（Ctrl+C）
   npm run dev
   ```
2. 检查数据库中的配置：
   ```sql
   SELECT * FROM api_settings WHERE category = 'okx';
   ```
